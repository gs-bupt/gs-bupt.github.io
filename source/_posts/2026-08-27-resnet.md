## 为什么需要残差网络

理论上，网络越深，表达能力越强；但在实际训练中，深层网络可能出现**退化问题**：训练误差反而变高。它不只是过拟合，也可能来自优化困难、梯度传播不稳定和参数初始化敏感。

ResNet 的核心思想是：与其让网络直接学习目标映射 $H(x)$，不如让若干卷积层学习残差 $F(x)=H(x)-x$，最后通过捷径连接得到：

$$
y = F(x, \mathcal{W}) + x
$$

如果新增层暂时学不到有用信息，只需让 $F(x)$ 接近零，模块就近似恒等映射，深度增加不会轻易破坏原有表示。

## 基本残差块

当输入和输出的通道数、空间尺寸相同时，可以直接使用 identity shortcut：

```python
from torch import nn


class BasicBlock(nn.Module):
    def __init__(self, in_channels, out_channels, stride=1):
        super().__init__()
        self.conv1 = nn.Conv2d(in_channels, out_channels, 3, stride, 1, bias=False)
        self.bn1 = nn.BatchNorm2d(out_channels)
        self.conv2 = nn.Conv2d(out_channels, out_channels, 3, 1, 1, bias=False)
        self.bn2 = nn.BatchNorm2d(out_channels)
        self.relu = nn.ReLU(inplace=True)
        self.shortcut = nn.Identity()
        if stride != 1 or in_channels != out_channels:
            self.shortcut = nn.Sequential(
                nn.Conv2d(in_channels, out_channels, 1, stride, bias=False),
                nn.BatchNorm2d(out_channels),
            )

    def forward(self, x):
        residual = self.shortcut(x)
        out = self.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        return self.relu(out + residual)
```

尺寸不匹配时，使用 $1×1$ 卷积调整通道数和步幅，这称为 projection shortcut。

## 常见网络结构

- **ResNet-18/34** 使用 BasicBlock，参数量较小，适合资源有限的场景。
- **ResNet-50/101/152** 使用 Bottleneck：$1×1$ 降维、$3×3$ 卷积、$1×1$ 升维，能在增加深度的同时控制计算量。
- 每个 stage 通常在第一个 block 使用 stride=2 完成下采样，随后保持尺寸不变。

训练时仍需关注学习率、BatchNorm 的 batch size、数据增强和权重初始化。ResNet 解决的是深度网络的优化和梯度传播问题，并不能替代正则化或数据质量治理。

## 小结

残差连接提供了一条更短的梯度路径，使网络可以逐步学习“需要修正的部分”。这套思想后来也被广泛用于检测、分割、Transformer 和其他深度模型中。
