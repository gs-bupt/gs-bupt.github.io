## JWT 是什么

JSON Web Token（JWT，RFC 7519）是一种用于在各方之间传递声明的令牌格式。它由 Header、Payload 和 Signature 三部分组成，通常以 `.` 分隔。JWT 的签名用于验证内容是否被篡改，但 **Payload 不是加密数据**，不要在其中放密码、身份证号等敏感信息。

## 安装依赖

早期示例常使用 `dgrijalva/jwt-go`，该项目已经停止维护。新项目建议使用维护中的 `golang-jwt/jwt/v5`：

```bash
go get github.com/golang-jwt/jwt/v5
```

## 定义声明并生成 Token

```go
package auth

import (
    "time"

    "github.com/golang-jwt/jwt/v5"
)

type Claims struct {
    UserID   int64  `json:"user_id"`
    Username string `json:"username"`
    jwt.RegisteredClaims
}

func GenerateToken(userID int64, username string, secret []byte) (string, error) {
    now := time.Now()
    claims := Claims{
        UserID:   userID,
        Username: username,
        RegisteredClaims: jwt.RegisteredClaims{
            Issuer:    "gs-bupt-blog",
            IssuedAt:  jwt.NewNumericDate(now),
            NotBefore: jwt.NewNumericDate(now),
            ExpiresAt: jwt.NewNumericDate(now.Add(2 * time.Hour)),
        },
    }

    token := jwt.NewWithClaims(jwt.SigningMethodHS256, claims)
    return token.SignedString(secret)
}
```

`RegisteredClaims` 提供 `iss`、`iat`、`nbf` 和 `exp` 等标准字段。有效期应根据业务设置，短有效期令牌可以降低泄露后的影响。

## 安全解析 Token

解析时必须校验签名算法，不能只相信 Token 自己声明的 `alg`：

```go
package auth

import (
    "fmt"

    "github.com/golang-jwt/jwt/v5"
)

func ParseToken(raw string, secret []byte) (*Claims, error) {
    token, err := jwt.ParseWithClaims(raw, &Claims{}, func(token *jwt.Token) (any, error) {
        if token.Method != jwt.SigningMethodHS256 {
            return nil, fmt.Errorf("unexpected signing method: %s", token.Method.Alg())
        }
        return secret, nil
    })
    if err != nil {
        return nil, err
    }
    claims, ok := token.Claims.(*Claims)
    if !ok || !token.Valid {
        return nil, fmt.Errorf("invalid token")
    }
    return claims, nil
}
```

## 实际使用建议

- 密钥放在环境变量或密钥管理服务中，不能提交到仓库；HS256 密钥应足够随机且长度充足。
- 服务端必须验证签名、过期时间、签发者和必要的权限声明。
- 登出和主动撤销需要额外的服务端状态，例如令牌版本号或黑名单；JWT 本身是无状态的。
- 对高安全场景可以使用 RS256/ES256，让签发方持有私钥，业务服务只保存公钥。
